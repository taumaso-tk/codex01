# ダーツ練習ノート

公開URL：https://darts-practice-note-tk.taumaso.chatgpt.site

このリポジトリは公開版のソースのバックアップです（2026-10-28時点）。GitHubへの保存とSitesへの公開は別操作で、自動同期ではありません。

## 最新の変更

- 履歴は最新5件だけを通常表示し、過去の記録は開閉式で10件ずつ追加表示します。
- 表示を省略した記録も保存・集計・コピーの対象です。

## 機能

- 3投ごとの最大間隔、トリプルリング内の本数、各投の×・○・☆を記録
- 固定IDを維持した編集・削除、保存後の入力欄への移動、数字キーボードの終了処理
- 日本時間で今日・今週・今月・全期間の集計、日別・週別・月別グラフ
- 前期比較、自己ベスト、ChatGPT用の生記録・集計結果コピー
- JSON書き出し・追加復元と変更前の自動退避

## 別のサーバーへの設置・復旧

`index.html`、`stats.js`、`dashboard.js`を同じフォルダに置き、HTTPSで公開してください。PHP・データベース・ビルド・追加ライブラリは不要です。コピー機能はHTTPS環境で利用してください。

URL（オリジン）が変わると、以前のブラウザ内データにはアクセスできません。移転前に旧サイトの「JSONを書き出す」で保存し、新サイトの「JSONから追加復元」で取り込んでください。

## 練習記録の保護

**このGitHubには個人の練習記録は含まれません。** 記録は使用したブラウザのlocalStorageに保存されます。ブラウザのデータ削除や端末変更に備え、定期的にJSONを別の場所へ保存してください。

- 保存キー：`darts-practice-v1`（従来と同じ）
- ID：`exportId`、旧記録は`legacy-<id>`。編集時も変更しません。
- 同じIDは1回だけ集計し、異なるIDは数値・日付が同じでも別ラウンドです。
- 読み込み時の移行・書き換えは行いません。追加の未知フィールドも保持します。
- 初回変更前の自動退避：`darts-practice-v1-backup-before-dashboard`
- 直前の自動退避：`darts-practice-v1-backup-previous`
- 退避に失敗した場合は保存を中止します。自動退避もブラウザのデータ削除では消えます。
- JSON復元は追加方式です。同じIDの既存記録は上書きせず、既存データを優先します。

## 集計仕様

1ラウンド＝3投。×＝50mm超、○＝50mm以内（ブル除く）、☆＝ブル。50mm以内率は○＋☆。トリプルリング内はリング内側の本数で、トリプル命中数ではありません。

未記録は各項目の分母から除外し、真の0は有効です。平均・割合は元ラウンド・有効投数で加重集計します。週は日本時間の月曜〜日曜。途中の週・月は前期の全期間との比較で、対象数も表示します。

自己ベストの率は、その項目の有効投数が30投以上ある練習日だけを対象とし、同率は最も早い日を採用します。

## 動作確認

Node.jsで `node tests/stats.test.cjs` を実行すると11件の自動テストを実行できます。

`tests/browser.cjs`はPlaywrightとChromiumがある開発環境用です。別途このフォルダをHTTPで配信して実行してください。既定URLは`http://127.0.0.1:8765`、変更する場合は`DARTS_TEST_URL`を指定します。実際の個人記録ではなくテスト用ブラウザで検証します。

iPhone実機のSafari・Chromeの確認は別途必要です。
